**Design assumptions (to confirm):**
- Timeline text, the step button label and the detail rows are server-driven in the app; the values shown are examples, not final copy.
- Which button style each screen uses (blue contained or navy) is not verified for every screen; the Figma file uses the blue contained style for the primary button.
- Components in the file are local ones bound to token variables, because no BB Pro Figma library link was available.

**Not yet designed / open design gaps:**
- 7.1 Create order (order summary), 7.2 Add vehicle (including the vehicle check bottom sheets), 7.3 Barcode and OTP consent, and 7.5 Cancel order have no frames.
- Order Status states other than "next action": waiting for customer payment, cancelled, activated.
